📋 INSTALLATION EN 3 ÉTAPES
═══════════════════════════════════════════════════════════════════

ÉTAPE 1: MIGRATION BASE DE DONNÉES (2 minutes)
─────────────────────────────────────────────────

1. Ouvrez phpMyAdmin: http://localhost/phpmyadmin
2. Sélectionnez la base "cosmos_beach"
3. Allez dans l'onglet "SQL"
4. Ouvrez le fichier: backend/migrations/001_create_password_resets_table.sql
5. Copiez-collez le contenu dans phpMyAdmin
6. Cliquez "Exécuter"

✅ Table password_resets créée!


ÉTAPE 2: CONFIGURER GMAIL (2 minutes)
──────────────────────────────────────

A) Générer un mot de passe d'application:
   1. Allez sur: https://myaccount.google.com/apppasswords
   2. Sélectionnez "Mail" et votre système
   3. Copiez le mot de passe généré (16 caractères)

B) Remplir le fichier .env:
   1. Ouvrez le fichier .env à la racine du projet
   2. Remplissez ces deux lignes:
      
      GMAIL_EMAIL=votre.email@gmail.com
      GMAIL_PASSWORD=xxxx xxxx xxxx xxxx

   3. Sauvegardez!

✅ Gmail configuré!


ÉTAPE 3: TESTER (1 minute)
────────────────────────────

1. Allez sur: http://localhost/Application-Defense/?action=login
2. Cliquez sur "Mot de passe oublié ?"
3. Entrez votre adresse email (celle du compte Cosmos Beach)
4. Cliquez "Envoyer le code OTP"
5. Vérifiez votre email (boîte mail + SPAM)
6. Vous devriez recevoir un code OTP
7. Entrez le code dans la page
8. Créez un nouveau mot de passe
9. Connectez-vous avec le nouveau mot de passe

✅ Système fonctionnel!
